# Linux & Windows Notes

Short, practical notes from my hands-on work with Linux (Ubuntu) and Windows.
Written as personal documentation: what I did, the commands I used, and what I learned.

## Linux (Ubuntu)
- **Package management:** `sudo apt update` to refresh package lists, `sudo apt install <package>` to install software, `sudo apt remove <package>` to remove it
- **Users & permissions:** `sudo adduser <name>` to create a user, `chmod` to change file permissions, `chown` to change file ownership
- **Basic terminal use:** `ls`, `cd`, `cp`, `mv`, `rm`, `grep`, `cat`, `pwd`

## Windows
- **Installation:** Created a bootable USB drive, booted from it, selected the disk and partitions, installed Windows, then installed drivers and system updates
- **Formatting / reinstalling:** Formatted the disk and performed a clean installation
- **Troubleshooting:** Diagnosed and fixed common issues such as missing drivers, slow startup, and software that would not install or run
  
## Hardware
- **Troubleshooting:** Fixed a computer that would not boot by cleaning it, following online troubleshooting guidance
